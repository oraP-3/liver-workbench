# Liver Workbench core 0.3

オフライン肝疾患ガイドライン参照アプリの実装用コアです。画面モックではなく、正式アプリから呼び出す症例データ構造、経時点・薬剤歴、共通スコア計算、参照資料台帳を収録します。

## 固定した設計

- 症例は氏名、生年月日、カルテ番号を持たず、利用者が付ける非識別の症例整理番号で管理します。
- 一症例に複数の評価時点を持ちます。基準日があれば実日付と相対日を双方向計算し、基準日がなければ相対日のみでも保存できます。
- 施設情報は評価時点にスナップショットとして残し、後日の施設設定変更で過去データを変えません。
- DILI薬剤歴は薬剤単位で開始・中止時期、再投与、疑わしさ、メモを保持します。
- スコアは診断や治療指示ではなく計算結果と適用条件を返す共通層です。

## 実装済み計算

- FIB-4
- FIB-3（研究指標として明示）
- Child-Pugh
- MELD
- MELD-Na
- Lille
- Maddrey's discriminant function（MDF）
- Japan Alcoholic Hepatitis Score（JAS）

JASは『アルコール性肝障害（アルコール関連肝疾患）診療ガイド2022』の表3に基づき、白血球数、Cr、INR（またはPT活性）、T-Bil、消化管出血またはDIC、年齢から算出します。8–9点を中等症、10点以上を重症とします。実装はスコアとガイドライン記載を返すのみで、治療開始・継続の自動決定は行いません。

## ALD治療参照

`src/ald.js`は、利用者が選択した病態と入力済みスコアに対応するガイド記載を返します。アプリ側でACLFや重症アルコール性肝炎を自動診断しません。表示時には次の出典階層を保持します。

- 国内Recommendation
- 国内ガイド本文
- 国内ガイド本文が引用する海外ガイドライン
- 有用との報告

MDF 32以上とプレドニゾロン40 mg/日・28日間は、国内Recommendationそのものではなく、国内ガイド本文が紹介するAASLDガイドラインの記載として返します。ACLF病態で発症する重症アルコール性肝炎への副腎皮質ステロイド検討は国内Recommendationとして返します。Lilleは1週後評価の計算値を表示しますが、今回確認できた資料に判定閾値がないため自動解釈しません。
